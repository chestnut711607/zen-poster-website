# 静心海报视觉规范

首页、共用页头、背景选择、图库弹窗和模板页已按此规范实现。编辑页保留现有功能，后续迁移。

## 颜色与字体

样式源文件：`src/design-system.css`，组件通过 `--zp-*` 变量引用。

| 用途 | 色值 |
| --- | --- |
| 品牌色、交互描边 | #74B7D9 |
| 辅助色、按钮、可点击文字 | #317093 |
| 页面底色 | #F5F5F5 |
| 卡片、页头 | #FFFFFF |
| 卡片悬停底色 | #EDF6FC |
| 正文 | #253746 |
| 次要文字 | #647582 |
| 分隔线 | #E2E8EC |

界面字体采用系统无衬线字体：Apple 系统字体、Segoe UI、苹方、微软雅黑。海报内原有字体与排版不变。品牌浅蓝用于点缀与状态，正文、按钮使用深色以保证阅读清晰。

标题 32px / 600，手机 28px；卡片标题 21px / 600；说明 13–15px；正文行高 1.65–1.7。间距以 4px 为基础，主要使用 8、12、16、20、24、32px。

## 布局与组件

- 页头：品牌文字“海报设计小魔方”、四步进度、使用帮助。完成的步骤可返回，未到达的步骤不可点击。窄屏进度另起一行。
- 首页：居中标题，桌面三列卡片，平板两列，手机单列。内容区最大宽度 984px（含左右 24px 留白）。
- 类型卡片外圆角 30px，内边距 12px，预览圆角 18px。图片完整保留 9:16 展示容器，标题与图片左缘对齐。
- 默认白卡片、轻阴影，尾部为模板数量与箭头。卡片整体可点击，进入背景选择；无选中对号。
- 暂未开放的类型仅在下方标注“即将推出”。已有模板文件下载入口按服务端数据保留。
- 常规操作按钮最小高度 44px；帮助弹窗圆角 30px，可关闭、按 Escape 退出，并恢复原焦点。

## 交互与动效

悬停仅改变卡片：品牌色描边、淡蓝背景、上移 3px、阴影微增强。页面底色保持不变。操作文字“开始制作”从透明渐显，按钮背景同时显现，箭头和文字占位保持稳定。

过渡时长 200ms，缓动 `cubic-bezier(.2, .8, .2, 1)`。键盘聚焦使用同样反馈并增加清晰轮廓；触屏及手机始终显示完整操作文字。系统设置“减少动态效果”时关闭位移和过渡。

加载阶段展示静态骨架；请求失败提供“重新加载”；图片失败提供可继续操作的替代提示。帮助弹窗使用 Radix 的焦点管理。

## 背景、图库与模板

背景未选图时使用等重的“本地上传”和“精选图库”两入口；已选图时替换为大图确认区及重新上传、更换图库、下一步操作。竖图和横图均按原比例完整预览，不裁切、不拉伸。

图库使用独立弹窗，包含主题筛选、图片选择和确认按钮。确认前不会替换原背景，取消可保留原选择；图库内部滚动，底部操作固定。

模板页使用纵向滚动网格，桌面四列、平板三列、手机两列；仅显示编号。点击选中后在底部“开始编辑”，返回时保留选择。模板预览使用实际背景和文案渲染；失败可重试。

### 图片浏览细节

图库为等宽不等高瀑布流：桌面四列、平板三列、手机两列；原比例图片不裁切。服务端提供考虑 EXIF 旋转的宽高，前端预留图片空间；切换分类回到列表顶部。分类栏和确认操作固定，仅图片列表滚动。

背景确认区桌面约 65% / 35% 分配预览与操作，外内边距缩小至 16px，图片内层无额外边距，预览高度 66vh（440–760px），手机上下排列。模板页“背景缩略图、当前背景名称、更换背景”整体居中，类型与数量独立靠右显示在网格上方。

### 最新交互修订

模板页移除类型数量徽标及卡片可见编号，预览图直接承载选择状态（描边、对号）；保留无障碍名称中的编号以区分按钮。当前背景信息仍居中。

图库按编号从左到右循环分配到各列，每列独立向下排列；DOM 与键盘顺序遵循编号，避免 CSS 多栏的纵向填充顺序与空列问题。

背景确认页在电脑端根据可用高度分配预览区域，常规窗口下一屏显示图片和操作。手机及极矮窗口允许自然滚动，确保操作可达。

## 编辑页

左侧使用“文案 / 背景 / Logo / 二维码”三个标签，其中“Logo / 二维码”为一个标签。文案保留字段编辑、标题字数提示和中文输入法支持；背景支持图库更换、本地上传、拖动与四角缩放、恢复默认、撤回重做；素材支持上传、更换、移除和失败提示，仅显示模板实际支持的素材位置。

右侧使用中性浅灰工作区，顶部为更换模板与下载海报，画布下方为缩放和适应窗口，底部标注导出尺寸。桌面面板独立滚动；手机预览在上、编辑面板在下，页面自然滚动。标签支持键盘左右键、Home、End 操作。
